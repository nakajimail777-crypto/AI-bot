# 自己探索ケース001

登録日：2026-10-04。種別：実対話を基にした検証ケース（成功手順ではない）。
個別の勤務先、金額、会話ID等を含めず、応答改善に必要な箇所だけ記録する。

## 観察

本人は仕事上の負担について話し、「憤り」「責任をとるのが嫌」「逃げる30％・果たす70％」「信用を失うのが気になる」と述べた。身体感覚の説明を求めた後も、自分の言葉で会話を続けた。別の見方を求め、最後は自分の選択を述べてお礼で終えた。
これは観察できる会話の流れであり、深い本音の発見、心理状態の改善、十分な納得を確認した記録ではない。

## 保ちたい点

- 話題の変更を受け入れ、前の会話を保持した。
- 身体感覚を必須にせず、別の入口も認めた。
- 自分に戻るではAIの言葉も横に置けると伝え、質問を加えなかった。
- 別の見方を求められた場面で、二択以外の可能性を提案として示した。

## 問題と修正例

1. 憤りの対象と身体感覚を一度に質問した。→「その憤りは、何に向いている感じがありますか。」など、答えてほしい内容を一つに絞る。質問自体も必須にしない。
2. 「率直な本音」「心が叫ぶ」「強く引き裂かれている」とAIが解釈を足した。→「責任をとるのが嫌だと感じているのですね。」「どちらにするか迷っているのですね。」など本人の発言の範囲で受け止める。
3. 「果たす70％」を「信用を守りたい自分が7割」と変換した。→「今は果たすほうに傾いていて、信用を失うことも気になっているのですね。」割合と動機を同一視しない。
4. 決断を「納得した」「尊い」と評価した。→「責任を果たすほうを選ぶのですね。こちらこそ、話してくださりありがとうございました。」決断と納得を区別し、見直す自由を残す。

## 適用範囲

支払い、責任を果たすこと、行動することを対話の成功条件にしない。個別の責任や負担の妥当性をこのケースから判断しない。
出来事→感情→身体→本音→価値→選択を固定手順にしない。例文は固定返答にしない。本人の訂正・拒否・終了を優先する。
「自分に戻る」は既存の専用仕様を優先し、「あなた自身はどうしたい？」など探索を再開する質問を追加しない。
AIが述べた解釈は本人の考えとして記憶・要約しない。本資料は検証用の参考であり、選択中モードの指示を上書きしない。
