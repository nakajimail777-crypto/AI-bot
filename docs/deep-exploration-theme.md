# 「深く降りる」テーマからの自己探索

実装日：2026年11月16日。基準：AI-bot main `165932c`。
作業ブランチ：`codex/theme-self-exploration`。既存APIと保存先を使う変更で、DB変更は不要。

## 使い方

1. 新しい会話の「テーマから自分を知る」、または自己探索メニューの「深く降りる」を押す。
2. 人との関係／仕事・活動／やりたいこと／最近気になること／自由入力からテーマを選ぶ。既に会話があれば「今の話題から」も選べる。
3. 「このテーマで始める」で会話を開始する。選択・取消だけでは送信しない。入力中の下書きは残る。
4. 具体的な場面から一問ずつ対話する。仮説を示す返答の「気持ちを確かめる」という見出しに合わせて、近い／一部近い／違う／まだ分からないの補助ボタンを表示する。
5. 補助ボタンは入力欄に言葉を入れるだけで、本人が直して送信できる。
6. 「今日はここまで」は短い振り返りを会話に保存し、成功後に探索を終了する。「通常対話へ」はAIへ送らず終了する。

テーマと探索状態はログイン中の既存下書きに保存する。会話やアカウントを切り替えたときは解除する。ゲストの開始・振り返りも既存のお試し回数を各1回使う。残数がなくても「通常対話へ」で終了できる。

## 対話の方針

テーマ→具体的な場面→本人の反応→一つだけ別の角度→根拠つきの気持ちの仮説→本人による照合と振り返り、を柔軟に使う。全段階の完走や新しい発見は必須ではない。

本人の訂正を優先し、否定された仮説を押し戻さない。同意だけで本人の気づきと確定せず、複数の気持ちや未確認のまま残す選択を認める。

終了時の振り返りは直近の正式な開始操作以降を今回の区間とする。以前の探索で確認した感情を、今回の発見として借用しない。「今の話題」から開始したときは直前の出来事を背景として扱える。開始記録が履歴の取得範囲にない場合は、その制約を踏まえて直近の発言だけを扱う。

## 実装

- `index.html`／`assets/deep-exploration-ui.js`／`assets/deep-exploration.css`：テーマ選択、補助ボタン、終了操作。
- `assets/app.js`：開始・継続・終了、下書きと再送IDの保持、会話切替時の解除。
- `lib/deep-exploration.js`：対話指示、入力検証、テーマをユーザーデータにする処理、振り返りの区間。
- `lib/chat.js`／`lib/guest-chat.js`：両APIへ接続。既存Gemini／OpenAI生成アダプターを使用する。

API追加項目は `deepTheme`（空または80文字以内、制御文字なし）と `deepAction: "finish"`。どちらも `deepExploration: true` の場合だけ受け付ける。終了と開始の同時指定は拒否する。テーマ・終了指定を保存文にも含め、同一リクエストIDによる内容変更を拒否する。キーの変更、新しい保存テーブル、モデル変更はない。

開始・終了は下書き、選択済み記憶、未送信PDFを消費しない。失敗した開始・終了を再読み込み後に再送しても同じIDを使う。ゲストの終了保存が成功したあと履歴取得だけが失敗した場合は、探索を終了したまま表示更新を案内する。

## 検証

- 公開前の全体テスト：395件成功、失敗0。
- 実AIで見つかった文言補足の調整後、deep、ログイン／ゲストAPIの関連テスト105件成功、失敗0。
- ブラウザー：ログイン状態の模擬画面とゲスト画面で、選択取消、開始、下書き保持、仮説ボタン、編集、振り返り、再読み込み、新規会話、429エラー時の入力保持を確認。
- 表示：PC幅、390×844、390×500で確認。予期しないコンソールエラーなし。
- 元のホームページのSHA256は実装前後で一致。

公開前に既存の比較サービス経由でGemini（gemini-3.7-flash）とOpenAI（gpt-5.4-mini-2026-03-17）の実APIを使用し、架空の会話で開始、場面、仮説、訂正、振り返り、別テーマの開始直後の終了を検証した。両AI合計18応答。OpenAIの最初の振り返りに本人が未確認の比較句が混じったため、最新の訂正を短く引用し、AIの比較・理由を接合しない指示を追加した。再検証で両AIとも本人の訂正を保った。別テーマでは以前の感情を借用しなかった。

実AI検証はこの変更の対話指示を使ったもので、本番のプロフィール・DBとは接続していない。API回帰テストと公開前のブラウザー確認はモックを使用した。本番画面での開始・保存・終了は公開後の確認対象。仮説ボタンの表示はAIの見出しに依存するため、見出しが出ない場合も自由入力で訂正・返答できる。AIの表現には揺れがあるため、この結果は以後の全応答を保証するものではない。
